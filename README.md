# 🌐 Portfólio / Currículo Web — Giulia Hernandes

Projeto de um **Portfólio / Currículo Web** desenvolvido como parte da formação em **Desenvolvimento de Sistemas** no SENAI. O projeto reúne informações pessoais, competências técnicas, tabela com projetos desenvolvidos e um formulário funcional para contacto.

---

## 📌 Sobre o Projeto

Este site foi construído utilizando práticas de **HTML5 Semântico**, focando na organização clara de conteúdos, acessibilidade básica e estrutura limpa de código.

### 👩‍💻 Sobre a Autora
* **Nome:** Giulia Hernandes
* **Curso:** Desenvolvimento de Sistemas — SENAI
* **Conhecimentos:** HTML, CSS e em aprendizagem de JavaScript e PHP.

---

## 🚀 Funcionalidades

- **Menu de Navegação:** Acesso rápido às secções de Sobre, Projetos e Contacto.
- **Apresentação Pessoal:** Descrição do perfil do estudante e lista de competências técnicas.
- **Tabela de Projetos:** Exibição estruturada dos projetos já concluídos, incluindo tecnologias utilizadas e hiperligações para os respetivos repositórios no GitHub.
- **Formulário de Contacto:** Organizado com `<fieldset>` e `<legend>`, contendo validações simples, seleções de assunto e caixa de texto para mensagens.
- **Rodapé com Contactos:** Hiperligações diretas para envio de e-mail e dados de contacto.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** (Estruturação semântica, tabelas, formulários e navegação)
- **PHP** (Processamento base do formulário)
